What do these controls and results mean?

Seed reproduces one generated layout; it is not a model confidence score. Pattern changes the mix of routes and confidence. Dynamic events adds revised assessments, route changes, resource failure, and simulated link disruption. Expected consequence is a scenario score, not a real-world casualty estimate. Both strategies run on the same inputs.

Model boundaries and deployment gaps

This is an advisory simulation. Protected zones are geometric footprints; track confidence and consequences are supplied scenario inputs. Peer mode models proximity groups and possible conflicting claims, but has no radios, routing, authentication, packet loss, or human authorization interface. It cannot be used to control a real system.
